# 📇 Freelance Platform Catalog (research)

Comprehensive catalog of client-acquisition platforms for the agent to target. Goal = reach many,
national + international. **Fit** = relevance to Manan (AI-engineer, cold-start/no-reputation, good
rates). **Access** = how the agent could ingest it (API / RSS / scrape / manual-assist).

Fit legend: ⭐⭐⭐ prime now · ⭐⭐ strong · ⭐ situational/later.
Access legend: 🟢 API/RSS (easy, clean) · 🟡 scrape (needs care, maybe camoufox) · 🔵 manual/profile-only (agent assists, human acts).

> Cold-start note: platforms that gate by reviews/Job-Success (Upwork/Fiverr) convert **worse** for
> Manan right now. Portfolio-first / skills-first / direct channels convert **better** (they judge the
> work, not a platform badge). Catalog is ordered with that in mind.

## What this means for the build (integration order)
1. **Already live (~8 platforms):** RemoteOK, WWR, JobSpy(×5), Google Maps.
2. **Next high-ROI, easy access (🟢):** Remotive, Working Nomads, Reddit API, Twitter/X API, Freelancer.com API.
3. **High-fit, needs scrape (🟡):** Contra, Wellfound, Upwork RSS, India boards (Truelancer/Cutshort/Instahyre) — use camoufox where anti-bot.
4. **High-rate, manual-assist (🔵):** Toptal/Gun.io/Arc/Turing/Braintrust/A.Team/Flexiple — agent drafts application + tracks; Manan applies (vetting is human).
5. Each new source = one small `fetch_<x>()` module + test (see `PLATFORM_COVERAGE.md` checklist).
