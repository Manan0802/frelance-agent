# Phase 1.5 — Engine A (Inbound / Bidding) Implementation Plan

> **STATUS: ✅ COMPLETE (2026-07-02).** All tasks A1–A8 done, 23 tests green, pushed to `main`.

> **For agentic workers:** implement task-by-task, TDD. Each task: failing test → run → minimal code → green → commit → `git push origin main`.

**Goal:** An inbound pipeline that pulls jobs from free boards (RemoteOK, We Work Remotely, JobSpy), scores them against Manan's portfolio, drafts personalized proposals for the top jobs, and surfaces them via the same review/CRM machinery as Engine B.

**Architecture:** Mirrors Engine B. Per-source fetchers return a common `JobLead` dict; an orchestrator dedups → scores (LLM) → writes proposals (LLM self-eval) → persists → WhatsApp digest. All network/LLM boundaries dependency-injected.

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy, Gemini, JobSpy, feedparser, httpx, pytest.

## Global Constraints
- Never auto-send. No mass spam. Data local-only except LLM calls.
- Gemini primary. Reuse Engine B patterns (`writer._score`, dependency injection).
- All fetchers injectable; tests never hit network.
